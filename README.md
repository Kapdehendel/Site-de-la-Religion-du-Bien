# La Religion du Bien — site web

Site statique en français, conçu pour être publié directement avec **GitHub Pages**.

## Contenu du dossier

- `index.html` : structure et contenu du site.
- `styles.css` : design responsive pour ordinateur, tablette et mobile.
- `script.js` : menu mobile et année automatique dans le pied de page.
- `documents/` : les quatre PDF de référence fournis avec le projet.

## Mise en ligne sur le dépôt existant

Dépôt repéré sur la capture d'écran :

`https://github.com/Kapdehendel/Site-de-la-Religion-du-Bien`

1. Télécharge et décompresse l'archive ZIP.
2. Ouvre le dépôt GitHub ci-dessus.
3. Clique sur **Add file → Upload files**.
4. Ouvre le dossier décompressé sur ton ordinateur et sélectionne **tous les éléments qu'il contient** (`index.html`, `styles.css`, `script.js`, `documents/` et ce README).
5. Dépose-les à la racine du dépôt, au même niveau que le fichier `README.md` actuel.
6. Si GitHub demande quoi faire des fichiers déjà présents, accepte le remplacement de `index.html` et ajoute les nouveaux fichiers.
7. Clique sur **Commit changes** pour enregistrer.

Le fichier `index.html` doit rester à la racine du dépôt. Ne téléverse pas seulement le dossier parent `site-religion-du-bien` : téléverse son contenu.

## Personnalisation

- Modifie les textes dans `index.html`.
- Modifie les couleurs, espacements et polices dans `styles.css`.
- Modifie le comportement du menu dans `script.js`.
- Pour ajouter un PDF, place-le dans `documents/` et ajoute un lien dans la section `#documents`.

## À propos du contenu

Le site présente les idées comme une proposition philosophique et spirituelle de l'auteur. Il distingue explicitement les propositions conceptuelles ou métaphysiques des affirmations susceptibles d'une vérification empirique. Les documents PDF originaux sont fournis dans le dossier `documents/`. La rubrique « Les textes originaux » contient un bouton « Télécharger » pour chacun des quatre PDF.

Le site utilise Google Fonts pour les polices lorsque la connexion internet le permet ; des polices système prennent le relais si nécessaire.
