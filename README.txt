PACK OBSERVATOIRE IFH-TEC — Installation GitHub Pages

1. Dans le dépôt Kapdehendel/Site-de-la-Religion-du-Bien, ajouter le fichier observatoire-ifh-tec.html à la racine (au même niveau que index.html).
2. Ouvrir index.html sur GitHub, cliquer sur Edit (crayon).
3. Suivre précisément le fichier LIEN-A-AJOUTER-DANS-INDEX.txt : un seul remplacement dans le menu.
4. Valider les deux changements (Commit changes).
5. Attendre la publication GitHub Pages et ouvrir :
   https://kapdehendel.github.io/Site-de-la-Religion-du-Bien/observatoire-ifh-tec.html

Aucun autre fichier du site n'est à remplacer.

CONTENU : première version de l'observatoire, avec références aux cycles, méthode V(t), estimations IFH historiques et graphiques en CSS. L'inventaire exhaustif des 140 prédictions et leur évaluation restent à vérifier et à ajouter : ne pas confondre cette première version avec une reconstitution complète des cycles.
